- Case number format: C2024XXXX (civil cases)
- Scanning approach: iterate case numbers, check documents for sheriff sale keywords
- Background scan running (session vivid-falcon): scanning C20240001-C20246000
- Key patterns found:
  - Most "writ" results are garnishments (debt collection), not sheriff sales
  - Need to filter for: "Certificate of Sale", "Writ of Special Execution", "Order of Sale", "Return of Sale"
  - HOA foreclosures show as "Foreclosure Complaint" in doc list
  - Example: C20240057 - Paloma II Homeowners vs. Sorensen (HOA foreclosure)
