## Maricopa Foreclosure Bot
**Repo:** https://github.com/oncorai/maricopa-foreclosure-bot
**Purpose:** Scrape Maricopa County for foreclosure/sheriff sale documents every 4 hours, alert via Telegram

### Architecture
- Node.js service
- Cron: every 4 hours
- Scrapes CE (Certificate) and DE (Deed) documents
- Parses PDFs for foreclosure keywords
- SQLite database for deduplication
- Telegram alerts to JFS

### Files
- `src/index.js` - Main entry, cron scheduler
- `src/scraper.js` - Maricopa County search + fetch
- `src/parser.js` - PDF parsing, foreclosure detection
- `src/db.js` - SQLite storage
- `src/notify.js` - Telegram alerts
