## Major Rebuild (Evening Session)

### Root Cause Found
Maricopa Recorder loads data via JavaScript from a **public API** (`publicapi.recorder.maricopa.gov`). FlareSolverr was useless — the HTML was just an empty shell. Rewrote the entire scraper to use the API directly.

### v2.0 Architecture
- Direct API calls (no CloudFlare, no FlareSolverr, no HTML scraping)
- OCR classification: downloads PDF, extracts first page image, OCRs title
- Looks for "Sheriff's Certificate of Sale on Foreclosure" and "Sheriff's Deed"
- Supabase Postgres for persistent storage (was JSON file before)
- Password-gated dashboard at https://oncorai.github.io/oncor-foreclosure-dashboard/

### Key Lesson: Not All CE Docs Are Foreclosures
- JFS caught this: most CE docs are trust certificates, not sheriff sales
- Only ~17 out of 271 CE docs are actual sheriff foreclosure sales
- OCR catches 3x more than party name filtering alone
- Title on the PDF is the definitive classifier
