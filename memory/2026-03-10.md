## Pima County Expansion — Court Scraper Development

### Key Discovery: Pima Court System is Scrapeable
- **URL:** `https://www.cosc.pima.gov/PublicDocs/search2a.aspx` (search) + `GetCase2.aspx?ID=XXX` (details)
- ASP.NET with ViewState tokens — need to GET tokens first, then POST search
- Case number format: `C2024XXXX` (4+ digit suffix)
- No captcha on court site (unlike Tyler Technologies recorder which has reCAPTCHA)
- Rate: ~0.15-0.2s delay between requests works fine
