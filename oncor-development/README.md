# Oncor Development — El Paso Land Deals

## Strategy
- Phase 1: Wholesale land deals (option/assign contracts)
- Phase 2: Buy and build (leverage concrete background)
- Target area: Everything within 1 hour of El Paso, TX
- Deal types: Residential, commercial, multi-family — all of it

## Coverage Area
- El Paso County: El Paso, Socorro, Horizon City, San Elizario, Canutillo, Anthony, Vinton, Clint
- Hudspeth County: Dell City, Sierra Blanca (fringe)
- Doña Ana County NM: Las Cruces, Anthony NM, Sunland Park, Mesilla
- Southern NM corridor

## Data Sources
- El Paso County tax records / delinquent parcels
- City of El Paso Planning & Inspections (zoning, plats, permits)
- LandWatch, LoopNet, Crexi, Zillow (land listings)
- El Paso CAD (appraisal district)
- TCEQ / utility availability
- Builder permit filings
